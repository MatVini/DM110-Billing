### Instruções
- Aplicar o script do banco de dados para criar as tabelas
- Clonar o projeto e executar `mvn clean install` na raiz
- Subir o servidor WildFly (configurações padrões da aula, standalone-full.xml)
- Fazer o deploy do .ear no WildFly, na pasta target
- Use a coleção do Postman disponibilizada na pasta docs
